## Checking objectives

se the command `lsobjectives <username>` and it will give you all the objectives listed starting from objectives 0 to how ever many they have.

Ex. `lsobjectives stuff_3541`

## Adding objectives

Use the commnad `addobjective <unsername> <objectives>` this will add a objective to target player. There are requirements for objectives to be added to a player, such as being a thief to steal captain's golden toilet, being a dragon for carp rift objective, or call in threat requires the target to be a ninja, etc.

Ex. `addobjective stuff_3541 CarpRiftObjective`

## Removing objectives

Use command `rmobjective <username> <objective number>`, where the objective number matches to the numbering from `lsobjectives`, starting from 0 up to however many objectives the target has.

Ex. `rmobjective stuff_3541 0`
