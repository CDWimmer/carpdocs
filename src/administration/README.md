# Administration

This page outlines the very high level tools for administration, with sub-pages dedicated to greater detail. 

## Admin ghost (aghost)

Unlike a regular ghost, an admin ghost (often shortened to "aghost") has tools, a large backpack, pockets, clothes slots, and **hands**. This makes it a lot easier to manipulate the world, all while remaining invisible to regular players. 

You can become an aghost via the button in the F7 menu or by using the `aghost` command. 

## The console

Mny functions are available via the UI, many more are available only as written commands. 

Whilst you _can_ write commands into the chat box by prepending it with a forward slash, (which a player would typically do for say, `/ghost`), you will find commands a lot easier to enter through the **command console**. The button for this will depend on your keyboard, but it is typically the button to the left of "1". e.g. `` ` `` for UK layouts, or `~` (tilde) for US layouts. 

A command is made up of the command itself, followed by any "arguments", separated by spaces. When entering commands in the console instead of the chat you will get a degree of autocomplete, and it will prompt you on what each argument is supposed to be. 

## View Variables (VV)

Often abreviated to VV, this is the system for modifying all the various statistics about an entity, such as a player, mob, or item. 

For the majority of tasks, this is most easily done with the VV UI, opened by either right clicking an entity and clicking "View Variables", or by hovering the cursor over the entity, and pressing 'ALT + V'.
